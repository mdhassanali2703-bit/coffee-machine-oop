# Coffee Machine OOP ☕

A simple coffee machine simulation built using Python and Object-Oriented Programming (OOP).

## Features
- Displays available coffee options
- Checks available ingredients
- Processes coin payments
- Calculates change
- Tracks available resources
- Generates a resource report

## Concepts Used
- Classes and Objects
- Methods
- Dictionaries
- Conditional Statements
- Loops

## Technologies
- Python

## How to Run
1. Download or clone this repository.
2. Open the project in PyCharm.
3. Run the main Python file.
